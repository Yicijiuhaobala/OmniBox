# OmniBox 学习中心低保真页面线框说明

> 文档状态：低保真方案草案
> 对应 PRD：[学习中心产品需求文档](./learning-center-prd.md)
> 本阶段目标：明确页面结构、信息优先级、主要交互与页面跳转，不进入代码开发和视觉定稿

## 1. 设计目标

- 让“今天做什么”成为学习中心的第一入口。
- 让用户随时知道当前任务、完成条件和下一步。
- 课程、练习、反馈、错题和复习在同一条路径中连续发生。
- 三个学习方向保持一致的操作习惯，但保留各自真正需要的训练界面。
- AI 只作为右侧可折叠导师，不把学习中心做成聊天应用。
- 维持 OmniBox 当前克制、桌面工具化的界面语言，避免渐变光效、悬浮球和满屏 AI 标识。

## 2. 全局框架

### 2.1 一级导航

OmniBox 原有左侧栏增加一个一级入口“学习中心”。进入后，主区域内部出现学习中心二级导航。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ OmniBox 全局侧栏  │ 顶栏：返回 / 前进 / 搜索 / 本地服务 / 主题 / 设置       │
│                   ├──────────────────────────────────────────────────────────┤
│ 首页              │ 学习中心二级栏 │ 当前页面                               │
│ 文件处理          │                │                                        │
│ 开发与数据        │ 今日           │                                        │
│ 图像与系统        │ 英语           │                                        │
│ 写作与识别        │ 基金           │                                        │
│ 内容工具          │ 大模型         │                                        │
│                   │ ─────────      │                                        │
│ 学习中心  ●       │ 复习           │                                        │
│                   │ 错题本         │                                        │
│ 服务与设置        │ 笔记           │                                        │
│                   │ 学习材料       │                                        │
└───────────────────┴────────────────┴────────────────────────────────────────┘
```

### 2.2 二级导航规则

- “今日”是默认页面。
- 英语、基金、大模型进入各自路线总览；具体单词、听力、案例、实验作为页面内标签，不继续增加永久侧栏项。
- “复习”显示三个方向的统一到期队列。
- “错题本”“笔记”“学习材料”提供全局筛选，也可从课程上下文进入预筛选状态。
- 页面关闭或切回其他 OmniBox 工具时保存当前任务位置。

### 2.3 页面宽度与密度

- 全局侧栏沿用当前约 `236px` 宽度。
- 学习中心二级栏建议 `168～188px`。
- 正文最大宽度 `1440px`，宽屏不无限拉长行宽。
- 课程正文推荐阅读宽度 `680～760px`。
- 右侧导师/笔记栏默认折叠，展开宽度 `320～380px`。

## 3. 页面流转

```text
首次进入
  └─ 学习档案与诊断
       └─ 今日学习
            ├─ 路线总览 ─ 课程详情 ─ 练习 ─ 反馈 ─ 复习
            ├─ 英语精听 ─ 听写反馈 ─ 生词/错题
            ├─ 基金案例 ─ 判断依据 ─ 风险反馈
            └─ 大模型实验 ─ 保存运行 ─ 项目证据

任意练习失败
  └─ 错题本 ─ 补强课程/相似练习 ─ 重新验证 ─ 关闭错题

阶段完成
  └─ 阶段测评 ─ 能力报告 ─ 调整下一阶段计划
```

## 4. 页面 W01：学习档案与初始诊断

### 4.1 页面目标

在不制造负担的前提下收集学习目标、时间和初始能力。允许跳过诊断，后续通过真实练习逐渐校准。

### 4.2 线框

```text
│ 建立你的学习档案                                      步骤 1 / 4          │
│ 这些信息只用于生成本地学习计划，可随时修改。                               │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│  你想学习什么？                                                            │
│  [✓ 英语]  [✓ 基金]  [✓ 大模型]                                           │
│                                                                            │
│  当前最重要的方向                                                          │
│  (●) 英语   ( ) 基金   ( ) 大模型                                         │
│                                                                            │
│  每天可投入时间                                                            │
│  [ 30 分钟 ▼ ]      学习日：[一][二][三][四][五][六][日]                  │
│                                                                            │
│  你的目标                                                                  │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │ 例如：六个月后能听懂日常英语并完成 3 分钟表达                       │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                            │
│  数据模式                                                                  │
│  ● 本地优先    AI 只在我主动点击辅导时使用                               │

│                                        [稍后设置] [下一步：英语诊断 →]    │

```

### 4.3 后续步骤

1. 英语：自评、词汇抽样、短听力和可选录音。
2. 基金：基础概念与风险认知，不询问具体资产金额。
3. 大模型：Python、机器学习和开发经验自评加小题。
4. 确认：显示每周总时长和首周计划草案。

### 4.4 关键交互

- 选择三个方向不会立即平均分配时间，以“主方向”和用户调整后的比例为准。
- 诊断结果展示“依据不足”或置信度，不直接给出夸张等级。
- 用户跳过后，相关能力状态标记为“待校准”。

### 5.3 关键交互

- “调整今日计划”允许修改总时长、拖动排序、缩短、替换或延后任务。
- 继续任务时恢复音频位置、输入内容、实验参数和未提交答案。
- 任务只有产生完成证据后才计为完成。
- 跳过任务不扣分，但要求选择“没时间、太难、不想学、已掌握、其他”，用于调整后续计划。

### 5.4 页面状态

- 首次无计划：展示“生成首日计划”。
- 已完成：展示今日总结、获得的证据和明日待复习数量。
- 逾期过多：优先提供“精简为 10 分钟”，不一次展示大量红色警告。
- AI 离线：任务照常使用，仅 AI 反馈入口显示不可用原因。

- “为什么推荐”必须使用真实练习证据。
- 大模型路线在公共基础后显示“应用开发”和“算法开发”分叉。


### 7.3 反馈态

提交后在练习原位置展开反馈：

```text

你的答案：What do you want to do?
参考内容：What d'you want to do?
                  └──── 弱读位置

遗漏原因：[没听清] [不知道表达] [拼写错误] [其他]
[再听一次] [查看解释] [加入错题] [下一题]
```

### 7.4 AI 导师展开规则

- 默认折叠，不遮挡正文。
- 当前练习未提交时，“直接给答案”不可作为默认快捷操作。
- 每条回复标记使用的课程范围；基金材料解释展示原文引用。
- 用户关闭导师后保留课程位置，不强制保留对话。

```text
│ 当前句  04                                                                  │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ 输入你听到的内容……                                                      │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│ [再听一次] [显示首字母] [显示关键词]                       [提交听写]        │

└──────────────────────────────────────────────────────────────────────────────┘
```

### 8.3 提交后的局部反馈

- 逐词显示正确、遗漏、误写和多余词。
- 点击单词弹出音标、释义、原速/慢速、美式/英式发音。
- “加入生词”先进入候选区，本次学习结束时统一确认。
- 所有句子完成后必须进行一次全文无字幕复听，才建议标记材料完成。

### 8.4 键盘操作

- `Space`：播放/暂停。
- `←` / `→`：后退/前进短时间。
- `Cmd/Ctrl + Enter`：提交听写。
- 快捷键只在输入框焦点和系统快捷键不冲突时生效。

- 每条反馈附原始音频位置和原句。
- 提供最多三句“建议重说”，防止一次修改过多。
- 明确反馈引擎和模式：本地基础分析或 AI 增强。

## 10. 页面 W07：基金案例与材料分析

### 10.1 页面目标

训练用户给出有依据的判断，不提供简单“买/不买”按钮。

### 10.2 线框

```text
┌───────────────────────────────────────┬──────────────────────────────────────┐
│ 案例材料                              │ 你的分析                             │
│                                       │                                      │
│ 某主动权益基金                        │ 1. 资金期限是否匹配？                 │
│ · 近一年收益：案例数据                │ [输入判断与依据……]                   │
│ · 最大回撤：案例数据                  │                                      │
│ · 管理费：案例数据                    │ 2. 主要风险是什么？                   │
│ · 用户资金六个月后需要使用            │ [输入判断与依据……]                   │
│                                       │                                      │
│ [查看指标定义]                        │ 3. 还缺少哪些信息？                   │
│ [打开关联课程]                        │ [输入需要补充的材料……]               │
│                                       │                                      │
│ 来源：教学案例 v1.0                   │ [保存草稿]             [提交分析]    │
├───────────────────────────────────────┴──────────────────────────────────────┤
│ 教育与模拟用途，不构成投资建议。                                             │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 10.3 反馈态

- 按“期限、风险、费用、产品类型、信息缺口、短期业绩偏差”逐项反馈。
- 显示用户已经覆盖和遗漏的依据。
- 允许存在多个合理方案，评分依据是分析完整度和风险意识。
- 涉及真实材料时，解释必须链接回原文页码或标记为一般知识。

### 10.4 材料阅读模式

左侧改为 PDF 页面和章节，右侧是结构化清单：投资范围、业绩基准、费用、风险、持仓、基金经理、待确认问题。点击清单证据定位原文。

## 15. 状态与异常页面

### 15.1 通用加载状态

- 本地查询使用骨架屏，但超过短时间后显示正在处理的具体对象。
- 材料解析、模型调用和实验运行必须可取消。
- 恢复页面时优先显示已保存内容，再异步加载增强数据。

### 15.2 空状态

- 无今日计划：设置可用时间并生成计划。
- 无复习：引导继续课程，不使用“太棒了，你全部掌握了”之类无依据文案。
- 无材料：选择内置材料或导入本地文件。
- 无能力证据：引导完成诊断和首个有效练习。

### 15.3 错误状态

- AI 服务不可用：保留用户输入，允许稍后重试或使用本地练习。
- 音频权限拒绝：解释系统设置路径，仍允许使用听力和文本练习。
- 材料解析失败：展示文件、阶段和可操作原因，不丢失原文件。
- 外部基金数据过期：展示最后更新时间并禁用依赖实时性的结论。
- 实验失败：保留参数、日志和用户结论区域。

## 16. 响应式与窗口适配

### 16.1 宽屏

- 使用二级侧栏、主内容和可折叠导师三列。
- 精听、基金案例和实验室使用左右分栏。

### 16.2 中等窗口

- 二级侧栏收起为页面顶部下拉或图标栏。
- 导师改为右侧抽屉。
- 左右工作台保持分栏，但允许调整比例。

### 16.3 窄窗口

- 内容改为单列，材料/输入在上，反馈/结果在下。
- 播放、录音和提交操作固定在当前任务底部，不遮挡正文。
- 不要求首期支持移动端，但窗口缩小时核心任务仍应完成。

## 17. 可访问性与键盘操作

- 所有标签、按钮、滑块、音频和录音控件提供可读名称。
- 对错、掌握状态和处理模式不能只依赖颜色。
- 支持键盘完成播放、提交、复习评级和页面导航。
- 音频波形提供时间与文本替代。
- 图表同时提供数据表。
- 导师抽屉打开后正确管理焦点，关闭后返回触发按钮。

## 18. 低保真评审检查表

- 今日页是否能在 10 秒内回答“现在该做什么”。
- 每项任务是否有明确完成条件。
- 三个方向是否共享学习习惯但没有被强行做成同一种页面。
- AI 是否始终处于辅助位置。
- 用户是否能从反馈回到错误证据和原始材料。
- 复习失败是否能转向补强而不是无限重复。
- 基金页面是否持续显示教育边界、来源和日期。
- 大模型实验是否要求用户先预测、再观察、最后写结论。
- 能力报告是否展示证据数量并处理样本不足。
- 本地、联网和 AI 模式是否在操作发生前清楚可见。

## 19. 下一轮需要确认的页面决策

1. 学习中心二级导航采用永久窄侧栏还是顶部标签。
2. 今日页默认混排三个方向，还是允许固定单方向日。
3. 课程详情是否允许导师与笔记同时展开。
4. 英语精听首期是否支持视频，或先只支持音频与字幕。
5. 口语首期使用本地基础分析还是直接依赖用户模型与语音服务。
6. 基金材料分析首期是否限定 PDF。
7. 大模型实验首期是内嵌执行还是生成并调用用户本地项目。
8. 能力报告是否默认显示 30 天，还是按学习阶段显示。
